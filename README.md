# KratzerScan Viewer

Statische Web-App (PWA) zum Ansehen von KratzerScan-Schadensberichten auf iPhone, Android und PC:
3D-Modell mit markierten Schäden, betroffene Bauteile, Empfehlung.

Die App enthält keine Daten. Berichtsdateien (`Schadensbericht_….glb`) werden lokal auf dem Gerät geöffnet
und nicht hochgeladen.

`model-viewer.min.js`: [@google/model-viewer](https://github.com/google/model-viewer) 3.5.0 (Apache-2.0).
